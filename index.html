TUTORIEL COMPLET

Comment installer et utiliser les 12 dépôts GitHub avec ou sans Claude Code ?

Vous avez découvert les 12 dépôts GitHub de ma précédente publication. Maintenant, passons à la pratique.

Ce tutoriel s’adresse à deux catégories de personnes :

  • Ceux qui possèdent Claude Code et souhaitent installer directement ces outils dans leur environnement de développement.
  • Ceux qui utilisent simplement Claude ou ChatGPT depuis leur navigateur et souhaitent quand même profiter de certaines de ces fonctionnalités.
Avant de commencer, une précision importante : tous les dépôts ne s’installent pas de la même façon. Certains sont des Skills, d’autres des serveurs MCP et d’autres encore des programmes qui doivent être installés sur un ordinateur.
Je vais vous montrer comment procéder dans chaque situation.
01

Si vous n’avez pas Claude Code

Vous utilisez simplement Claude ou ChatGPT sur votre téléphone ou votre ordinateur ? Voici ce que vous pouvez faire.

M1Installer un Skill dans Claude sans Claude Code

C’est notamment possible avec Humanizer. Un Skill est un ensemble d’instructions qui apprend à Claude à effectuer certaines tâches selon une méthode précise. Humanizer permet de retravailler des textes pour leur donner un ton plus naturel.

Préparer le Skill

  1. Rendez-vous sur le dépôt : https://github.com/blader/humanizer
  2. Cliquez sur le bouton vert Code.
  3. Sélectionnez Download ZIP pour télécharger le dépôt.
  4. Décompressez le fichier ZIP sur votre ordinateur.
  5. Repérez le dossier contenant le fichier SKILL.md.
  6. Si le dépôt contient plusieurs fichiers utiles, conservez toute la structure du dossier.
  7. Recompressez le dossier du Skill au format ZIP, en gardant le dossier du Skill à la racine de l’archive.

L’importer dans Claude

  1. Allez dans Customize → Skills.
  2. Cliquez sur le bouton +.
  3. Sélectionnez Create skill, puis Upload a skill.
  4. Importez le fichier ZIP que vous venez de préparer.
  5. Activez le Skill avec le bouton correspondant.

Vous pouvez maintenant demander à Claude :

« Utilise Humanizer pour retravailler ce texte. Je veux un résultat naturel, fluide et humain, sans modifier le sens de mes phrases. »

Et voilà !

À savoir : l’importation des Skills dans Claude nécessite que l’exécution de code soit activée. Vérifiez cette option dans Settings → Capabilities. Cette fonctionnalité est disponible sur les forfaits Claude compatibles, y compris Free.

Et avec ChatGPT ?

ChatGPT ne permet pas d’installer directement un Skill GitHub comme un Skill permanent dans une conversation classique. Mais vous pouvez utiliser ses instructions manuellement :

  1. Ouvrez le dépôt GitHub.
  2. Repérez et ouvrez le fichier SKILL.md.
  3. Copiez son contenu.
  4. Ouvrez une conversation ChatGPT.
  5. Collez les instructions en précisant que vous souhaitez qu’il les applique.

Par exemple :

« Voici les instructions du Skill Humanizer. Lis-les attentivement et applique-les désormais au texte que je vais te transmettre. Respecte les règles et les méthodes décrites dans ce document. »

ChatGPT pourra alors appliquer ces instructions dans cette conversation. Ce n’est toutefois pas une installation permanente du Skill. Cette méthode est particulièrement utile pour Humanizer et certains Skills qui reposent essentiellement sur des instructions textuelles.

M2Connecter un serveur MCP à Claude sans Claude Code

Un serveur MCP permet à Claude d’utiliser directement les fonctionnalités d’un service externe. Prenons Apify MCP Server : il permet notamment de rechercher des données sur des sites web en utilisant les outils disponibles sur Apify.

Dans Claude

  1. Ouvrez https://claude.ai.
  2. Cliquez sur votre profil ou vos paramètres.
  3. Accédez à Settings → Connectors.
  4. Cliquez sur Add custom connector.
  5. Donnez un nom au connecteur : Apify.
  6. Dans le champ de l’adresse du serveur MCP, collez : https://mcp.apify.com
  7. Cliquez sur Continue, puis sur Add.
  8. Une fenêtre de connexion Apify devrait s’ouvrir dans votre navigateur.
  9. Connectez-vous à votre compte Apify et autorisez la connexion.

C’est terminé ! Ouvrez une nouvelle conversation Claude, activez Apify dans les outils disponibles et faites un premier test :

« Utilise Apify pour rechercher des commerces à Cotonou sur Instagram. Je souhaite identifier ceux qui n’ont pas de site web indiqué dans leur bio et organiser les résultats dans un tableau. »

Claude pourra utiliser les outils Apify auxquels vous avez donné accès. Vous n’avez pas besoin de Claude Code, de Node.js ou d’installer un serveur sur votre ordinateur pour cette connexion distante. La connexion utilise le serveur hébergé par Apify.

Connecter Apify à ChatGPT

C’est également possible avec ChatGPT en utilisant son système de serveurs MCP personnalisés, si la fonctionnalité est disponible sur votre compte. Voici la procédure documentée par Apify :

  1. Ouvrez ChatGPT dans votre navigateur.
  2. Accédez à Settings → Connectors ou à la section des applications.
  3. Cliquez sur +, puis sur Add custom MCP server.
  4. Donnez le nom Apify.
  5. Collez l’adresse : https://mcp.apify.com
  6. Sélectionnez l’authentification OAuth.
  7. Validez l’avertissement de sécurité.
  8. Cliquez sur Create as a plugin.
  9. Connectez-vous à votre compte Apify et autorisez l’accès.
  10. Ouvrez une nouvelle conversation, tapez @ et sélectionnez Apify.

Vous pouvez ensuite demander à ChatGPT d’utiliser Apify pour effectuer une recherche.

Attention : la disponibilité des connexions MCP personnalisées dépend du forfait et des autorisations du compte ChatGPT. Si vous ne trouvez pas cette option, vous ne pourrez pas suivre cette procédure sur votre compte.

M3Utiliser Claude Desktop pour les outils locaux

Il existe aussi une autre possibilité : Claude Desktop, l’application de bureau de Claude. Elle permet notamment d’installer des extensions de bureau qui exécutent des serveurs MCP sur votre ordinateur. Pour les extensions disponibles dans son catalogue :

  1. Téléchargez Claude Desktop depuis https://claude.com/download.
  2. Installez et ouvrez l’application.
  3. Allez dans Settings → Desktop app.
  4. Repérez la rubrique Extensions.
  5. Cliquez sur Manage, puis sur Browse extensions.
  6. Choisissez une extension et cliquez sur Install.
  7. Renseignez les éventuelles clés API demandées.

Pour installer une extension personnalisée au format .mcpb, utilisez Install Extension dans les paramètres avancés.

Attention : tous les dépôts GitHub ne fournissent pas un fichier .mcpb. Cette méthode ne permet donc pas d’installer automatiquement n’importe quel dépôt.
02

Si vous avez Claude Code

Si vous possédez Claude Code, vous pouvez aller plus loin. Claude Code est un environnement de développement dans lequel Claude peut lire et modifier les fichiers de vos projets, exécuter des commandes et installer des outils. Vous pouvez l’utiliser depuis le terminal ou depuis l’onglet Code de Claude Desktop.

01Hyperframes

Hyperframes permet de créer des vidéos à partir de HTML, CSS, animations et médias, puis de les exporter au format MP4.

Prérequis : Node.js 22 ou supérieur, et FFmpeg installé sur votre ordinateur. Ouvrez le terminal dans le dossier de votre projet et exécutez :

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Une fois installé, ouvrez Claude Code et demandez :

« Utilise Hyperframes pour créer une vidéo de présentation de 30 secondes avec un titre animé, des sous-titres et une transition entre les scènes. »

Vous pouvez également installer les Skills indépendamment du plugin :

npx skills add heygen-com/hyperframes

Documentation : github.com/heygen-com/hyperframes

02Google Workspace CLI

Cet outil permet d’interagir avec les services Google Workspace, notamment Drive, Sheets, Gmail et Calendar.

Prérequis : Node.js et npm, un compte Google, et un projet Google Cloud configuré avec les API nécessaires.

npm install -g @googleworkspace/cli

Ensuite, configurez votre accès :

gws auth setup

Puis connectez votre compte Google :

gws auth login

Pour tester la connexion :

gws drive files list --params '{"pageSize": 5}'

Vous pouvez ensuite demander à Claude Code de vous aider à créer un rapport dans Google Sheets ou à automatiser certaines opérations Google Workspace.

Documentation : github.com/googleworkspace/cli

03Apify MCP Server

Dans le terminal, exécutez :

claude mcp add apify https://mcp.apify.com -t http

Lors de la première utilisation, Claude vous demandera de vous connecter à Apify. Une fois la connexion autorisée, vous pourrez demander à Claude Code d’utiliser Apify pour rechercher des données sur des sites web.

Documentation : github.com/apify/apify-mcp-server

04Scrollcraft

Scrollcraft est un Skill qui aide à construire des sites web immersifs avec des animations déclenchées par le défilement. Dans Claude Code, exécutez :

/plugin marketplace add nateherkai/scroll-craft
/plugin install nateherk-design

Ensuite, demandez par exemple :

« Utilise Scrollcraft pour créer une landing page immersive pour mon entreprise. Je veux des animations au défilement, une typographie soignée et une expérience fluide sur mobile. »

Le projet nécessite notamment Node.js 18+, FFmpeg et Chrome pour certaines opérations de vérification. Il utilise également Playwright Core.

Documentation : github.com/nateherkai/scroll-craft

05Humanizer

Dans Claude Code, exécutez :

/plugin marketplace add blader/humanizer
/plugin install humanizer@humanizer

Puis utilisez :

/humanizer

Collez ensuite votre texte. Vous pouvez également lui demander de retravailler un document en conservant votre style d’écriture.

Documentation : github.com/blader/humanizer

06Agent Skills

Ce dépôt contient des compétences pour améliorer différentes étapes du développement logiciel. Dans le terminal :

npx skills add addyosmani/agent-skills

Pour consulter les compétences disponibles :

npx skills add addyosmani/agent-skills --list

Vous pouvez ensuite demander à Claude Code d’utiliser les compétences installées pour analyser, planifier ou construire un projet.

Documentation : github.com/addyosmani/agent-skills

07Expo Skills

Expo Skills apporte à l’IA des connaissances spécialisées pour développer, mettre à jour et déboguer des applications mobiles avec Expo et React Native. Dans Claude Code, utilisez :

claude plugin install expo@claude-plugins-official

Ensuite, ouvrez votre projet Expo et demandez :

« Utilise les compétences Expo pour créer une application mobile avec un écran d’accueil, une navigation par onglets et une page de profil. »

Documentation : github.com/expo/skills

08Supabase Agent Skills

Ces Skills aident Claude à travailler avec Supabase, notamment pour les bases de données et l’authentification. Dans le terminal :

npx skills add supabase/agent-skills

Pour installer les Skills dans votre projet, exécutez cette commande depuis le dossier du projet. Vous pouvez ensuite demander :

« Utilise les compétences Supabase pour m’aider à créer une base de données avec une table utilisateurs et une table produits. Explique-moi les relations entre les tables et accompagne-moi dans la configuration. »

Documentation : github.com/supabase/agent-skills

09Stripe Best Practices

Ce Skill aide l’IA à suivre les bonnes pratiques lors de l’intégration de paiements Stripe dans une application. Pour installer les Skills Stripe avec le CLI :

npx skills add https://docs.stripe.com

Vous pouvez ensuite demander à Claude Code :

« Utilise les bonnes pratiques Stripe pour m’aider à intégrer un système de paiement dans mon application. Commence par déterminer la méthode de paiement la plus adaptée à mon projet et prépare une intégration en environnement de test. »

Documentation : github.com/stripe/ai/…/stripe-best-practices

10Playwright CLI

Playwright CLI permet d’automatiser les interactions avec un navigateur pour tester un site web.

Prérequis : Node.js 18 ou supérieur et un agent de développement compatible. Installez l’outil :

npm install -g @playwright/cli@latest

Vérifiez son installation :

playwright-cli --help

Installez ensuite les Skills :

playwright-cli install --skills

Vous pouvez maintenant demander à Claude Code :

« Utilise Playwright CLI pour tester mon formulaire d’inscription. Remplis les champs, vérifie les messages d’erreur et prends des captures d’écran des résultats. »

Documentation : github.com/microsoft/playwright-cli

11Claude Security

Ce plugin permet d’analyser un projet logiciel pour rechercher des vulnérabilités et proposer des corrections.

Prérequis : Claude Code, Python 3.9 ou supérieur, et un projet contenant le code à analyser. Dans Claude Code, exécutez :

/plugin marketplace add anthropics/claude-plugins-official
/plugin install claude-security@claude-plugins-official
/reload-plugins

Ensuite, lancez :

/claude-security

Vous pourrez choisir d’analyser l’ensemble du projet, les modifications récentes ou de demander des propositions de correction.

Documentation : github.com/anthropics/claude-plugins-official/…/claude-security

12OpenSEO

OpenSEO est un outil de référencement naturel qui permet notamment de rechercher des mots-clés, suivre des positions et analyser des concurrents. Pour connecter son serveur MCP à Claude Code, exécutez :

claude mcp add --transport http --scope user openseo https://app.openseo.so/mcp

Autorisez ensuite la connexion à OpenSEO lorsqu’elle vous est proposée. Vous pourrez demander :

« Utilise OpenSEO pour rechercher les mots-clés les plus pertinents pour mon site et identifier les opportunités de référencement sur mon marché. »

OpenSEO nécessite une clé DataForSEO pour accéder aux données SEO. Son service hébergé propose également une formule d’essai et des offres payantes.

Documentation : github.com/every-app/open-seo

03

Quelques conseils avant de commencer

1. Vous n’avez pas besoin d’installer les 12 outils.
Choisissez ceux qui correspondent à vos besoins. Si vous créez des applications, Expo, Supabase et Stripe peuvent vous intéresser. Si vous travaillez dans le marketing, Apify et OpenSEO méritent votre attention.
2. Ne confondez pas gratuit et sans frais.
Certains dépôts sont open source, mais utilisent des services externes payants ou nécessitent des crédits.
3. Ne copiez pas aveuglément les commandes.
Vérifiez toujours la documentation officielle et comprenez ce que vous installez. Ne partagez jamais vos clés API ou vos mots de passe.
4. Testez avant de passer à un vrai projet.
Commencez par une petite tâche, vérifiez que tout fonctionne, puis passez à des réalisations plus importantes.

Le plus important

Vous n’avez pas Claude Code ? Vous pouvez tout de même utiliser certains Skills directement dans Claude, connecter des serveurs MCP ou réutiliser des instructions dans ChatGPT.

Vous avez Claude Code ? Vous pouvez installer les outils compatibles et leur permettre d’intervenir directement dans vos projets.

Il faut simplement choisir la bonne méthode selon le dépôt et l’assistant que vous utilisez.

Bon apprentissage à tous !
